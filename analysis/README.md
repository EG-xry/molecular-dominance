# Reproducibility package

Run the commands below from this analysis directory. The manuscript and supporting text are in ../manuscript/.

## Obtain excluded inputs first

This package excludes the O'Neill source workbook (no compatible redistribution grant established), the two Zheng source documents (CC BY-NC 4.0), and 18 MaveDB metadata records carrying CC BY-SA or CC BY-NC-SA licenses. INPUT_RIGHTS.json gives each file's rights, attribution, access route, and checksum. The 2,801 compatible metadata records and all 16 analysis score CSVs (CC0) are retained. Original source terms remain attached to compatible inputs.

Run `python3 restore_external_inputs.py --download`, or provide independently obtained matching files using `python3 restore_external_inputs.py --input-cache /path/to/cache`. The cache mirrors the listed paths. Retrieval fails if a remote input has changed; it never substitutes current metadata for the historical snapshot. Obtain the recorded snapshot from an explicitly supplied matching historical copy when a checksum differs. The 18 missing records are archived under their original licenses at https://doi.org/10.5281/zenodo.24438963. Download `MaveDB_2026-09-26_original_licenses.zip` from there and pass it with `--metadata-bundle /path/to/MaveDB_2026-09-26_original_licenses.zip`. The current API does not reproduce most omitted historical records. Analysis can run offline after these explicit, checksum-verified retrieval steps. The ZIP alone is not a complete offline input bundle.

## Reproduce the analyses

Run commands from this directory. The verified environment is Python 3.10.19; install dependencies with `python3 -m pip install -r requirements.txt`. The pinned packages include openpyxl for the source workbook. No GPU is required. Bootstrap and full profile simulations take longer than simple table-generating commands.

The working checkout holds inputs under `data/` and clinical query snapshots under `clinvar_cache/`. The distributable S1 ZIP deliberately omits the O'Neill workbook, the two Zheng source documents, and 18 MaveDB metadata records; the file-level [rights manifest](submission-2026-09-29/input_rights_manifest.json) explains each decision and gives source routes and hashes. After unpacking S1 File, run `python3 restore_external_inputs.py --download` from its `analysis/` directory, or use `--input-cache /path/to/cache` with independently obtained files mirroring the recorded paths. Only exact checksum matches are accepted. The current MaveDB API does not reconstruct all excluded historical records. Those 18 records are archived under their original licenses at https://doi.org/10.5281/zenodo.24438963 and are supplied through `--metadata-bundle /path/to/MaveDB_2026-09-26_original_licenses.zip`. The ZIP alone is not a complete offline input bundle.

After the excluded inputs have been obtained and verified, the analyses run without sibling project directories or network access. `run_clinvar.py --refresh` deliberately replaces the cached clinical snapshot and should not be used to reproduce the reported snapshot.

Run SCN5A before profile, bounds, clinical, and crosswalk analyses. The bounds driver cross-checks the existing `profile_scn5a.csv`; use the packaged full-profile output when those calculations are unchanged, or run the full profile driver first. Run controls, moment, TP53, and the hotspot driver before Figure 2, and the survey before its validation. `run_profile.py --quick` changes replication counts and overwrites the same files; use the full run for the manuscript table.

Analysis filenames differ from submission numbers: `Schematic` is **Fig. 1**, `TitrationMain` is **Fig. 2**, `Figure2` (KCNQ2 origins and TP53) is **Fig. 3**, `Figure1` (SCN5A floor) is **Fig. 4**, `Figure3` is supplementary **S1 Fig**, and `Titration` is supplementary **S2 Fig**; the build copies them under their submission names. SCN5A variants are named on NP_000326.2 by `hgvs.py`, which checks every reference residue; `scn5a_specifications.csv` lists source and HGVS names. The bounds are conditional on the specified activity scale, dose factor, assembly model, and analyst-chosen fraction scenarios. No activity-profile bounds are calculated from the uncalibrated Kv7 or TP53 scores. TP53 synonymous/nonsense summaries diagnose candidate anchors. The hotspot-anchored slopes are a conditional and partly circular calibration sensitivity, not an independent biological calibration.

All figure scripts take their colours, fonts, printed width, and shared drawing helpers from `palette.py`: a blue ramp for wild type, model, and ordered quantities, teal for adjusted or fitted quantities, and gold for mutant subunits and for raw or flagged quantities. Figures are drawn at 7.5 inches, the PLOS ONE maximum width, in Arial at 8 to 11 pt in the main figures, so the journal need not rescale them.

## Inputs and interpretation

SCN5A inputs are published summary measurements from O'Neill et al. (2022), *Genetics in Medicine* 24:1238–1248, [PMC9262418](https://pmc.ncbi.nlm.nih.gov/articles/PMC9262418/). Workbook SHA-256: `bc8943213fb0f02ebd4a58628ea3bc8d27e9d3bc0685740d08b33c956fca28fe`. The panel contains 50 missense variants and W822X. The mixed arm is normalized to Sleeping Beauty-only WT; the alone-arm WT-plasmid reference is interpreted as landing-pad-only WT. The 218.4% WT+WT control motivates a linear-dose mutant fraction of 0.5421 and a floor of 45.79%; with cells treated as independent, the strictest test retains p.Asp356Asn and p.Gly1711Cys. Treating the p.Trp822Ter product as inert instead gives an 82.46% floor and ten retained variants with propagated control uncertainty, or eleven with that higher floor fixed. These are different conditional calibrations, and robustness is calculated separately for each. The four-variant intersection belongs only to the conditional p=0.5 specification with the observed WT+WT reference. Source labels use NP_932173.1; the MANE crosswalk uses NP_000326.2. Above source position 1077, labels generally shift down by one, with reference-residue checks for each mapping.

KCNQ2 endpoint/control data come directly from MaveDB `urn:mavedb:00000664`. This is not the Vanoye KCNQ2/KCNQ3 study and has no explicit publication link in its metadata. The endpoint ranks are descriptive: current at −40 mV depends on activation shift and the conductance/current scale measured at +40 mV, invalidating an independent-endpoint null. The published-origin raw-moment subtraction retains offset–signal cross terms; control centring and intercept specifications have distinct conditional estimands. Joint residue bootstraps compare specifications without interpreting their spread as a biological correction. Other voltage panels are extracted tables from Zheng et al. (2022), *Genome Research*, and Vanoye et al. (2022), *JCI Insight*. `run_kv7_provenance.py` re-derives both extracts from the original workbooks (192/192 and 34/34 rows, no mismatches in the recorded provenance check) and records the inclusion rules in `kv7_provenance.json`. The Zheng workbook must be obtained separately for the distributable package; compatible Vanoye inputs are included with attribution.

TP53 accessions are `00000068-b-1` (common Giacomelli alone predictor), `00000068-a-1` and `00001235-a-1` (mixed responses), and `00001213-a-1` (HCT116 mut/Δ, separately). Scores are used as deposited. The paired missense analysis excludes frameshifts and stops; nucleotide records with the same protein change are averaged. The final common mixed cohort has 7,446 variants; the separate HCT116 comparison has 3,423. A separate parser retains synonymous and nonsense variants for the candidate-anchor diagnostics in `tp53_anchors.csv/json`; this does not alter the matched missense cohort.

The archive screen uses the 26 September 2026 short-record metadata snapshot: 2,819 records, 2,809 eligible and 1,288 experiment sets. Four search routes flagged 46 sets, classified as five verified mutant/WT designs, two ambiguous and 39 other designs. Three verified designs have both archived arms; none states input or achieved fractions in the searched metadata. The first label set contains 36 inherited classifications with an unrecorded reader/model plus ten completed by Codex GPT-6. A blind Codex repeat agrees on 43/46 labels (93.5%; Cohen’s κ = 0.80, chance agreement 0.68), which measures repeatability. The author then checked all 46 sets individually, knowing the AI labels, and made the final calls (`data/archive/survey_author_check.csv`): the three disputed sets are other. Publication checks are a separate evidence source in the design table. No unflagged sample was reviewed, so recall and prevalence are unestimated.

Clatot Supplementary Table 1 and Supplementary Fig. 3 state the input fractions as 0.10, 0.25, 0.50, 0.75 and 0.90. These define the primary titration analysis; literal conversion of the text’s ratio shorthand is retained as a sensitivity. At the stated inputs, all six NaV1.5 series fit a single dimer profile per series after either correction. All 26 candidate tests and seven fit tests use both Bonferroni and Holm correction. Source-design results are printed in S1 Tables N1–N5; every literal-ratio result and joint sensitivity grid remains in the CSV/JSON files. The tests treat recordings as independent and digitized SEMs as known error scales.

Passing tests verify selected software properties. They do not validate random assembly, achieved subunit fractions, transportable nuisance moments, or clinical utility. Residue-bootstrap intervals condition on published measurements and omit shared-reference/batch uncertainty. The SCN5A counts of two, ten or eleven remain conditional on the chosen control calibration, replication treatment, and assembly, abundance, endpoint, and response assumptions. Complete poisoning of a mutant-containing complex attains the floor; it does not explain a breach below it.
